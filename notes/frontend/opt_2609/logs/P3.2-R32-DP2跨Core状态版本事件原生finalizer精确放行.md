## 首个真实阻断与修复

原生产链接产物 `/tmp/dense_train_dp2_20260917_fenced_i/full_dp2_two_step.linked.json` 的物理梯度门禁已检查 2,176 actions、248 D2D edges、82 state-version edges、120 梯度路径和 22 对跨 core EVENT。旧冻结 finalizer 在 source-bound 动作体上准确拒绝 `action has a non-canonical mixed record body`：新的 `state_dma_lowering/STATE_IO` 将 `LSU_STORE→EVENT_SET` 或 `EVENT_WAIT→LSU_LOAD` 绑定到同一个 GlobalAction，而 C++ 白名单尚只允许单条 LSU。

源码提交 `4a270945`：只有 linked manifest 带**唯一合法** `DENSE_DP2_ROUTE_PLAN/v1alpha1` 锚、片段确为 `state_dma_lowering/STATE_IO` 且只声明一个唯一动作时，该动作才额外允许上面两种恰好两条指令的顺序。其它 mixed body 仍按原规则拒绝；原有 EVENT_TAG SET/WAIT 端点、引用、credit 及 runtime core 约束未被放宽。真实 source 中 22 个 STORE 各恰好一个 SET，22 个 LOAD 各恰好一个 WAIT；98 个不跨 core 的 STORE 维持无 SET。
