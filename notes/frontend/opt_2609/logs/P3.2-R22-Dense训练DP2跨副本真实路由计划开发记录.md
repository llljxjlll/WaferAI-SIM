# P3.2-R22 Dense TRAIN DP2 跨副本真实路由计划

## 本轮目标与已实现内容

从 R21 已验证的完整 IR0/N3 2×2 训练源图和两份真实 TP replica placement，推导 **DP 轴**对应的两个跨副本物理组。生产构造 `build_dense_dp2_route_plan(plan, placed, context)` 使用放置图的Die位置及 fabric 全部真实链路、port、资源容量，为 TP shard0 创建 DP rank0/1 = Die0↔Die2、为 TP shard1 创建 DP rank0/1 = Die1↔Die3 的双向 XY PairRoute，并在真实 `PhysicalFabric` 上重验每跳。组轴是 DP，不是原有本地 TP 组。

计划包含 30 个真实状态×2 SGD step 的 60 个源绑定条目：每条精确匹配两份 IR1 内的 WGRAD/FP32 DP SUM/SGD 节点、真实 trainable StateDecl ID、当前 TP shard 的原生梯度字节（32、128、256、384 或 512）与 child→root、root→child 双向 PairRoute。`DenseDP2RoutePlan.validate_against` 会从相同生产 plan、正式放置与 context 重新推导全计划并逐字段比对；篡改任一小梯度为固定2048B即拒绝。
