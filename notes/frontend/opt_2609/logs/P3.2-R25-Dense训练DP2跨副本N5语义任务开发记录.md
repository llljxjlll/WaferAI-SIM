# P3.2-R25 Dense TRAIN DP2 跨副本 N5 语义任务

将 R24 已验证的60条真实跨副本 WGRAD→FP32 SUM→SGD 路径中的每一条8个 N4 action 投影为严格校验的 N5 `SemanticTask`，总计480条，覆盖 Die0/1/2/3。每个 SEND/RECV 按真实 `PairRoute` 生成 `SemanticFlow`：共240个本地收发流实例，FP32真梯度分片32/128/256/384/512B。60个 SUM 为 `SemanticTaskKind.REDUCE`，保留源FP32 `ReductionContract` 和 rank-major 输入；另外为每个梯度及两个副本记录合计120条真实 WGRAD producer 边界和120条 SUM/WAIT→SGD consumer 边界。投影结果以完整 N4 route plan 重新物化校验，删动作、伪造SGD目标均拒绝。

验证：`PYTHONPATH=.:llm/test/frontend/unit python3 -m unittest llm.test.frontend.unit.test_full_dense_training_dp2_n5_tasks -v` 修正 fixture 导入后的独立正反测试2/2 PASS；修改前曾联合执行既有 N4 两项和新增两项共4/4 PASS；测试代码还断言Die覆盖、240流、60 REDUCE、120+120边界、真实分片字节和两项负测。

**范围边界：** 当前是经过严格字段校验的跨副本 N5 `SemanticTask`/`SemanticFlow` 侧记录，尚未将其合并到每副本 `IR2ProjectionResult`/跨副本 `TrainProjectedIR2`，也尚未构造全局 `GlobalActionDAG` 的真实数据/控制依赖或N6原生指令。现有 N5 主投影对没有本地 standalone plan 的 DP SUM 仍严格拒绝；在完整全局合并与 SGD 消费依赖接通之前不得声称 N5 全链或 DP2 原生训练通过。
