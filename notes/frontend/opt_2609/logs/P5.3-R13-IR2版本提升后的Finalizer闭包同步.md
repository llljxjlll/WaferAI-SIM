# P5.3-R13：IR2 版本提升后的 Finalizer 闭包同步

日期：2026-09-19。R12 源码提交后，以最终源码启动正式 2×6 全 Die双 Fresh。fresh0 的生产编译和 64 KiB SRAM 分配成功，生成 25,234,093B 的 segment 0 linked manifest，但 C++ finalizer 在生成 NPUP 前拒绝：`linked_program_manifest.input_digests: mixed manifest input closure is not exact`。因此该次运行没有进入 ProgramIO 或 NpuSim，不计 Fresh 成功。

根因是 R12 将 `IR2_PROJECTION_RESULT_SCHEMA_VERSION` 从 `v1alpha13` 提升到 `v1alpha14`、DAG 从 `v1alpha14` 提升到 `v1alpha15`，Python producer 已输出新版本，而 `program_finalizer.cpp` 的 mixed manifest upstream/train lineage 两处仍把 projection 精确白名单固定为 `v1alpha13`。实际 manifest 已包含 `ir2_projection/v1alpha14`，所以 finalizer 的 `expected_inputs` 集合漏掉该项，最终与 `actual_inputs` 不相等。

修复提交 `e5cdf3d2` 同步 finalizer 两处 projection schema，并更新 segmented state-transfer 测试 fixture 的 projection/DAG 版本。增量重建 finalizer 后，直接对失败作业保留的同一 linked manifest 重新执行完整 finalizer，退出码为 0并生成 NPUP：
