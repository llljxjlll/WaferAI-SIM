# P3.2-R27：DP2 实际梯度长度的原生 FP32 SUM 与非紧凑 stride 回归

日期：2026-09-16。继 R26 的 N6 物理 buffer、银行、stride schema 校验后，在 `collective_data_v1_prim_selftest.cpp` 用实际 SRAM 字节对两份 DP replica 输入做原生 `LOCAL_REDUCE SUM`：每份长度覆盖源图导出的 32、64、128、256、384、512B，FP32 1.0+2.0 的每元素实测输出必须恰为 3.0，未被读作输入的对齐填充字节置为 `0x55`。64B 对齐的 rank stride 与输入 true bytes 分开核验；当 stride 大于 true bytes 使用 V3 显式物理 stride，紧凑情况使用旧 V1 的隐式 stride `0`，两版序列化与反序列化保持各自合同。测试 SRAM 区域扩为 2048B 以容纳两份 512B 输入与输出，未修改生产 primitive 或模拟器的容量配置。

工作区原生 `cmake --build /tmp/tp4-stride-build --target npusim -j2` 退出 0；`/tmp/tp4-stride-build/npusim --collective-data-v1-prim-selftest` 输出 `[COLLECTIVE DATA V1 PRIM] PASS (32 checks)`、退出 0；`--isa-v1-selftest` 退出 0。N6 Python 六种真 shard 正例与 stride 篡改负例也已通过。源码测试提交 `07d7bb1b`，此前 N6/schema 和 Python 测试为 `358c8837`、`6cbf867f`。

这是 primitive 级物理真值回归。DP2 完整 Dense 训练的跨 replica DTE、N5 全局 DAG、SGD 与两步原生 NpuSim 尚未闭环；本测试不提升其 M1/M2 完成状态。
