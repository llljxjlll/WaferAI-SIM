# P3.2-R8：Dense 两步训练 loss/DP 梯度数学合同

日期：2026-09-15。范围：P3.2 全参数独立 requirement 的数学定义，**源合同与组件能力，不是 full training 运行验收**。

真实原始 train-forward CE 以 `CrossEntropyReduction.NONE` 返回每 row 的 FP32 loss；新增独立 per-row `dLoss` seed 固定非零 FP32 1.0，定义全局训练目标为所有 row CE loss 的**和**。每 rank 对自身 row 产生参数梯度后，同一参数的 DP replica 以 FP32、rank-major `SUM` 规约并广播；SGD 按原 `learning_rate` 消耗这个**未再次归一化**的 sum。它不应被报告为每样本平均 loss 或平均梯度；如果另有 MEAN 模式，必须提供来源明确的 FP32 scale/per-row seed 和一致的 optimizer 归一化实体。

改动新 `schema/full_dense_gradient_requirements.py` 为 source-backed `DenseGradientLossObjective.PER_ROW_CE_SUM`、`DenseGradientDPReduction.FP32_RANK_MAJOR_SUM`、`loss_gradient_seed_per_row=1.0` 与 `optimizer_gradient_normalization=false`，`validate_against(plan)` 独立重派生，零 seed/误称 `fp32_mean`/暗加 SGD 梯度归一化均拒绝。训练 sidecar scoped seed ones16B 是 ProgramIO seed/probe 范围，native CE_BACKWARD 只计真实时序，不能因数值 seed 合法自动声称 model-functional。
