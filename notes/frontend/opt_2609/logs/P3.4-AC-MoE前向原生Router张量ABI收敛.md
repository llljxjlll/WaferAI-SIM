# P3.4-AC：MoE 前向原生 Router 张量 ABI 收敛

- 当前公开 0x27/0x28 物理计算读取 FP16 router scores，另读取每 token 五个 little-endian INT32 字段（token index、source rank、selected expert、expert home rank、slot），即 20 B/token。此前 full TRAIN IR0 的 score 是 FP32、route ID 是 `(tokens,)` INT32（4 B/token），无法作为该真实 primitive 的 operand。
- 双层 EP1/EP2 全模型前向 source 现声明 FP16 `(tokens, expert_count)` score、INT32 `(tokens,5)` frozen route table；官方 IR0 exact-shape validator 与 MoE coverage 同步。EP1 4 token 每层 score 8 B、route table 80 B。旧 `(tokens,)` 张量即使重签 IR0 仍被 source validator 拒绝。Source 仍保留原 E2E operation/trace identity、router/dispatch/expert/combine 和 shared residual 边。
- 新 source payload bridge 直接读取相同 MoECompileSequence 每层的真实 P2 assignments，按 `<IIIII` 序列化 token/source/expert/home/slot，校验 expert slot 无洞或重复、IR0 route value 和 E2E trace digest 一致，签出每层 80 B 与 SHA-256。EP1/EP2 两层 source 均核实；伪造 selected expert 字段或换 sequence 在 reopen 中拒绝。payload 仍未作为 ProgramIO 输入装载。
- 实测：`PYTHONPATH=llm/test/frontend/unit:. python3 -m unittest llm.test.frontend.unit.test_moe_full_train_forward_ir0 llm.test.frontend.unit.test_moe_full_train_ep_ir1_source llm.test.frontend.unit.test_moe_full_train_expert_microplan`，56 tests PASS；另定向原生 ABI 正/负测 1 test PASS；`PYTHONPATH=llm/test/frontend/unit:. python3 -m unittest llm.test.frontend.unit.test_moe_full_train_route_table_source` 14 tests PASS（含 fixture 继承测试）。
- 本阶段只是 source tensor ABI 对齐。现有 `moe_full_train_router_route_sram.py` 可从签名 P2 trace 生成 80 B route blob，但尚未将 blob 作为 full TRAIN 官方 ProgramIO/BufferABI 的真实加载源，route-freeze/dispatch/combine、专家 scratch 多记录降低、共享 dCombined/backbone backward 和一次 invocation 两完整 SGD steps 仍未打通。TRAIN/M1 门禁继续关闭。
- `schema/ir0.py` 同时有 Dense TP rank-shape 的不重叠共享工作区改动；经协调由 Dense agent 先整文件提交（含本阶段 MoE shape 数行），本阶段其余 MoE 文件后续 exact-path 单独提交。请以最终 commit SHA 为准核对源绑定。
