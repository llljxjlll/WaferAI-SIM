# P3.1-R10：核几何修复后 1×4 Dense 推理双 Fresh 真实运行

## 目标与结论

在 P1.1-R1 修复每 Die 原生 NpuSim 核几何之后，重新从两个空目录、两个独立 Python 进程编译和执行固定两层 Dense 的 Prefill→Decode→Decode 序列。两个运行均 `runtime_status=verified`，所有逻辑 Die 0–3 分别落在 NpuSim 的真实物理 Die 0–3，native east/west D2D 链路有非零流量。因此本记录只支持 **M1 Dense 推理 1×4 resident 的一项双独立真实运行**；其他形状、Dense 训练、MoE 推理/训练、offload、M1–M3 总里程碑尚未由本记录证明。

## 源码与命令

源码冻结在本地提交 `e1c3b5e66d60b505952551fcf76b103e122403ad` 的独立 worktree `/tmp/m1-native-geometry-freeze`，原生工具为 `/workspace/build-debug-final/npusim_program_finalizer`、`npusim_program_io_selftest`、`npusim`。两次使用相同 CLI 配置，输出分别在 `/tmp/m1-geometry-1x4-fresh0` 和 `/tmp/m1-geometry-1x4-fresh1`；每次命令的唯一变化为输出目录。

```bash
PYTHONPATH=/tmp/m1-native-geometry-freeze:/tmp/m1-native-geometry-freeze/llm/test/frontend/unit \
python3 -m llm.test.frontend.integration.run_dense_sequence_runtime_canary \
  --mesh-size 1x4 --output /tmp/m1-geometry-1x4-fresh0 \
  --finalizer /workspace/build-debug-final/npusim_program_finalizer \
  --resolver /workspace/build-debug-final/npusim_program_io_selftest \
  --npusim /workspace/build-debug-final/npusim \
  --simulation /tmp/m1-native-geometry-freeze/llm/test/program/p5_behavioral_simulation.json \
  --timeout 900 --compile-timeout 2400
```
