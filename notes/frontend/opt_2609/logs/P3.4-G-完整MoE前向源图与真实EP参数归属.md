# P3.4-G：两层完整 MoE 前向训练源图与严格 EP 参数归属

## 开发目标和实现

以真实 TP1 两层 Dense 训练前向源图与同一模型、V16、H4、I8、EP2、top1 的生产 MoE 两层训练 compile sequence 为双重输入，新增 typed `MOE_ROUTER`、`MOE_ROUTE_FREEZE`、`MOE_DISPATCH`、`MOE_EXPERT_FORWARD`、`MOE_COMBINE` IR0 OpKind 和冻结路由 workload。源图保留 Dense embedding、两层 norm/rope/attention/qkv/residual、末层 norm/head/CE 前向主干，逐层删除 Dense gate_up/SwiGLU/down 原节点及其四份参数，新增 router→INT32 route freeze→FP16 dispatch→两个专家各自三权重投影→FP16 combine→原 residual2 真 DATA 输入链。两层 32 个前向节点、27 个训练参数状态，保留 11 个共享原参数 StateDecl 原 ID→新可训练状态一一映射，四份 EP router 权重和 12 份专家权重各有原始 E2E version0 StateVersion、具体 E2E TensorValue logical_rank 与已生产链接 StateABI Die home 证据。`generation` 固定原真实状态版本 0，不借它冒充 EP die 或 TP shard。

每层 router FLOPs64、两专家各 384FLOPs/192B 原模型三投影参数、combine FLOPs32；冻结输入 `(3,3,5,7)` 从原工作负载产生并有实际 16B INT32 ProgramIO sidecar 与固定 native0x23 索引 trace 源 bytes 比对（native0x23 独立真实运行由对应原生阶段负责）。强约束 exact 原模型 H/I/E/V、原始路由 digest/histogram/专家 owner 与原生产绑定组，每一步源中任一专家为空时明确拒绝当前正 work 图，后续须版本化 zero-work 实体；没有凭空造 GEMM。现只有 step0 前向，step1 必须从 SGD 后 StateABI version1 读取，当前输入不足即拒绝。

旧 `DenseIR0Validator` 对未经 typed E2E EP owner phase 包裹的裸 MoE IR0 明确拒绝；新的 `MoeFullTrainForwardValidator` 单独重新调用完整 shared Dense 原算子校验、源图 DAG、parameter reads 与 StateDecl 原义一致、各层真 MoE DATA 依赖及 source EP Die provenance，不更改 Lite Train 或旧 Dense job 合同。

## 测试与验收

真实 source fixture 的 MoE IR0/workload 32/32 PASS，新加结构有效的 layer0/1 residual 绕过 combine 和 expert1 冻结路由 digest 篡改故障 2/2 PASS；共 34 项关注源图检查。缺少任何层/专家 owner、专家1 冒名专家0 Die、错绑 layer route、step1 无版本1参数、旧裸 IR0 自报完整模型等均负面拒绝。旧 Dense 20 项回归有 19 PASS；`test_partial_cannot_have_an_external_postprocess_consumer` 唯一旧 HEAD 本就失败（fusion boundary 错误比断言期待的 reduction-consumer 错误更早产生），本阶段未松动 fusion 校验。

## 未完成的全模型训练门禁

本阶段只交付真实两层**完整前向 IR0 来源和证据**，不是生产 place→project→scheduled DAG→LinkedProgramManifest→ProgramIO→NpuSim 的 full TRAIN 运行验收。共享与专家的 CE backward、norm/attention/embedding/rope/residual 真逆向、每参数 FP32 WGRAD 与 DP/EP 梯度、optimizer SGD 状态版本0→1→2、top1 router 梯度合同和两步同一 timeline 均尚未闭合；裸片段或独立 native0x23 成功都不能代替训练闭环。后续首先建立 typed MoE TrainPlacedIR1/投影任务、保留 embedding INT32 token tape 至原生0x23，再补完整 shared+expert 反向和 SGD；任何 source graph 或无 gradient producer 的旧 motif 应保持 fail closed。
