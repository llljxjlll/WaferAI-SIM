# P5 全形状 schema/preflight 矩阵开发记录

日期：2026-09-14

## 目标与边界

本切片为 `1≤H,W≤10` 的全部 100 个矩形和 Dense/MoE 推理/训练四类负载建立版本化 schema/preflight 报告，共 400 个 case。每个 case 都调用统一的 `WorkloadRunRequest` 和 `materialize_workload_preflight`，没有用手写摘要代替 placement、graph、transport 或 memory planner。

本切片不调用 finalizer、resolver 或 NpuSim。所有 report 和 matrix 的 runtime 状态固定为 `not_measured`；preflight capability 只声明 `schema_only`，因此 materialization 状态保留 `unsupported` 并包含 `family.runtime`，不能由 400 个静态 case 推导 runtime support。

## Schema 与报告内容

新增：

- `schema/workload_shape_matrix.py`
- `passes/workload_shape_matrix.py`
- `test/frontend/unit/test_workload_shape_matrix.py`

`WorkloadShapeCaseReport` 绑定完整 request 和 request digest，并记录：

- mapping mode、active/idle Die 集合；
- layer/step/token/rank 数、operation/value 数与 bytes、transport request/payload、memory state/reserved bytes；
- materialization ID/digest；
- placement、logical graph、transport request 和 memory plan digest；
- materialization/unsupported requirements/runtime status；
- 10×10 large-mesh canary 标记。

`WorkloadShapeMatrix` 使用独立 schema 版本和稳定 ID，强制 canonical `(rows, columns, family)` 顺序，并重新检查精确 400 个键、case/report/request digest 唯一性、四个 10×10 canary 和 `runtime=not_measured`。缺失、重复或额外 case 均 fail closed。

## 固定模型与映射

四类 case 共用固定的两层 FP16 tiny 模型维度：hidden=4、intermediate=8、attention/KV heads=4、head_dim=1、最大序列 8；MoE 使用 4 experts、静态 top-1。推理执行 Prefill 2 token 加 2 个 Decode step；训练执行 2 个完整 SGD step。

映射分两类：

1. `mesh_scaled_all_dies`：60 个 shape、240 个 family case。根据物理 rank 数选择可整除固定模型的 TP，MoE 再选择合法 EP，其余为 DP；所有 Die active。
2. `fixed_four_rank_idle_dies`：40 个 shape、160 个 family case。使用跨 mesh 均匀分布的四个非连续 active Die，Dense 为 TP2×DP2，MoE 为 TP2×EP2，其余物理 Die 保持 idle 并仍属于 mesh。

10×10 的四个 family 均走全 100-rank 映射，作为本切片的代表性大 mesh preflight canary。

## 测试结果

代表 case 先行验证：1×1 Dense 推理、2×3 非连续 idle-die MoE 训练和 10×10 全 100-rank Dense 训练均成功生成 report。

完整矩阵命令：

```bash
PYTHONPATH=/workspace:/workspace/llm/test/frontend/unit \
time -p python3 -B -m unittest test_workload_shape_matrix -v
```

结果：6/6 测试通过，完整 400/400 case 全部 materialize；wall 373.18 秒、user 371.14 秒、sys 2.00 秒。测试覆盖精确 case 集合、转置 mesh、非连续 active mapping、两类映射、稳定 ID/canonical order、缺失/重复/额外 case、runtime 能力不误提升及四类 10×10 canary。

该 373 秒测试属于发布级 preflight 全矩阵，不运行 400 个真实 simulator。日常回归应使用代表 case；正式声称 P5/M3 runtime 完成仍需要真实 lowering、runtime evidence、资源测量和超过 10×10 的实际 canary。
