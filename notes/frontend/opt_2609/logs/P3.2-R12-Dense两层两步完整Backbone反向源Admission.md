# P3.2-R12：Dense 两层两步完整 Backbone 反向源 Admission

日期：2026-09-16。本阶段在 R11 的精确 gap gate 上继续补全 source-only admission；没有修改公共 ISA/codec/finalizer 旧文件，没有生成物理 backward IR、BufferABI、record 或 runtime 成功证据。

## 完成的源覆盖

新增 `dense_backbone_reverse_source_admission.py`，从同一个生产 `FlexibleDenseTrainPlan` 与 `DenseFullTrainRequirements` 逐 leaf 重建反向源合同。每个 leaf 保存真实 forward input/output identity、typed derivative family、rank bytes、family profile、参数 StateDecl shards，以及需要时的逆 collective kind。

TP3/DP2 两层图现在具有 32 个显式 source contract：

- 9 个 GEMM dX：验证真实 X/W/Y logical shape、无 producer 的 FP16 weight、每个 TP shard 的参数 StateDecl，rank X/dY 与 FP32 dX bytes。
- 5 个 RMSNorm dX：验证 activation/gamma/output、epsilon 已由 IR0 validator 冻结、rank rows/hidden 与 FP16 saved/upstream/output bytes。
- 8 个 TP collective dX：AllGather 的导数显式为 ReduceScatter，ReduceScatter SUM 的导数显式为 AllGather；rank input/output bytes 在反向交换。
- 2 个 causal TRAIN Attention dX：绑定 packed QKV、真实 attention output、rank Q/KV heads、head dim、sequence 与精确 causal pair 数。
- 2 个 SwiGLU dX：绑定 concat gate/up source 与输出，验证 rank `2I -> I`，保存输入、upstream 和双分支输出 bytes。
- R11 已验证的 2 个 RoPE 与 4 个 residual leaf 直接复用其 position/GQA 与双输出 source witness。

TP1 图没有实体 collective，故为 24 个 leaf。两个形状都按 step0/step1 静态展开：TP1 为 48 条，TP3/DP2 为 64 条；所有 ref→family 输入到 R11 gate 后 `missing=0`。

## 边界

这里的“source admission 完整”只表示每个 `required_backbone_backward_ref` 都有从真实 forward IR0 派生的 family/geometry requirement。结果字段 `physical_program_admitted` 固定为 false，篡改为 true 后 `validate_against` 明确拒绝。

仍未完成的物理工作包括：逐 leaf backward IR0 producer、上游梯度的同值 BufferABI 链、GEMM FP32 dX 与其后 FP16 primitive 间的明确 cast/accumulation 规则、collective gradient transport、公共 RoPE/residual record、所有参数 WGRAD 消费、DP SUM、SGD/store 与 step1 version load。source gate 归零不代表 P3.2、FUNCTIONAL、两步 NpuSim 或 M1 完成。
