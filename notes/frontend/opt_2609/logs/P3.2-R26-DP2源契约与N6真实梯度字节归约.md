# P3.2-R26：DP2 完整训练源契约与真实 FP32 梯度字节归约

## 目标与完成范围

为二维 TP2×DP2、两层、两步 Dense 训练的源图建立严格契约，并允许 N6 的 DP2 本地 FP32 归约使用源导出的真实 TP shard 字节长度。此阶段只验证源图、N3 放置和 N6 schema 字节布局；跨 DP replica 的物理同步还需 N4/N5/DTE/原生运行。不能以本记录宣称 M1 全矩阵或 DP2 端到端训练完成。

## 开发内容

- 对 `full_dense_training_two_step_dp2_source` 单独准入 TP2×DP2 训练图及四个物理 rank 的 StateAccess；同一 TP shard 的 replica rank 映射为 `rank % tp`，完整要求 READ/READ_WRITE 及两步 STORE0→LOAD1 控制边。DP1 契约保持原范围。
- 原生 WGRAD 的 FP32 DP-partial 输出只允许精确一个 DP2 SUM AllReduce，检查每 shard 真实字节数、DP axes、角色和 participant，SGD 只消费对应同步后的 gradient；禁止将同步 collective 当作参数 WGRAD 或为它伪造 StateAccess。
- TP 反向 dX 的状态读取要求覆盖两个 replica 的四个物理 rank。
- N6 `LOCAL_REDUCE` DP2 FP32 准入真实非零、4 字节对齐 `task.bytes`，继续核对两个 rank 的 tight input、64B physical stride、输出位置、SRAM region 容量及越界。原固定 2048B 仅适用于旧样例，真实模型 shard 含 32/128/256/384/512B。

## 测试与物理边界
