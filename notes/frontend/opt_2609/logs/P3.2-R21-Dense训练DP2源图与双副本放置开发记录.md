# P3.2-R21 Dense TRAIN 2×2（TP2×DP2）源图与放置

## 目标和当前结论

在既有 1×4、TP4/DP1 完整两步单调用真实物理训练之上，建立 **2×2、TP2/DP2** 的可验证源图与两副本物理放置，继续实现真实跨 DP 的 FP32 WGRAD SUM。**本阶段只验证到 N3 放置与 N4 分区；没有 N4 跨副本计划、N5/N6、ProgramIO 或 NpuSim 运行证明，不视为 2×2 完整训练或 M1 完成。**

## 生产实现

- 独立于原始前向计划，在完整反向源图加入 TP2×DP2 两轴逻辑 mesh；旧 DP1 TP-only 源不受影响。每个 forward/CE/backward/WGRAD 按原逻辑节点由正式 N3 放置实例化为 `__dp0`、`__dp1`，四个真实物理 rank 为 0、1、2、3。
- 参数 WGRAD 是 FP32、DP partial；每参数每步新增 `CollectiveKind.ALL_REDUCE`、`ReduceOp.SUM`、`mesh_axes=(DP,)`、`CollectiveRole.GRADIENT` 的 typed 节点，rank-local bytes 严格由本 TP shard 的梯度决定（32、128、256、384、512 字节），SGD 只消费同步后 FP32 值。同步源节点 ID 绑定训练态真实 `TRAINABLE_PARAMETER` StateDecl，未填充为旧的 2048 字节训练 carrier。
- 每个真实 replica 和 TP shard 的前向参数 READ、GEMM dX READ、Embedding WGRAD READ、SGD READ_WRITE 显式绑定 owner rank。两步一条逻辑 step0 SGD→step1 forward 版本边经 N3 实例化为每副本一条物理边；不复制相同起止节点的逻辑控制边。
- 新 DP2 producer tag 限定二维 mesh 和访问映射：N3 每副本只保留该副本的真实访问，映射到其 TP 组局部 rank0/1，保留两个副本的独立 HBM StateBinding。原 DP1 路径与其校验继续保持。
