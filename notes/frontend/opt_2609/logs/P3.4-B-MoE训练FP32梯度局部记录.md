# P3.4-B MoE 专用训练梯度与共享时间线开发记录

## 本阶段目标和当前范围

对现有 1×2、EP2、两层、两个 SGD 步的同一声明模型，保留 rank0 共享 Dense spine、rank1 专家，在 MoE **独立单层训练块**中建立有物理操作与 SRAM 载体证据的反向传输、专家三投影 DGRAD/WGRAD、FP32 梯度 cast、gate 梯度树同步与 SGD。后续将每层前向置于真实 shared CE 之前，每层反向置于 CE 后，以一个生产 `LinkedProgramManifest` 和一轮 NpuSim drain 验收；**当前未达到完整训练程序 runtime**。

## 初始失败见证与物理修复

- 原 EXPERT_DGRAD 每个 `m=2,H=4,I=8` 专家只有一个 `MATMUL` 的 64 FLOPs，无法满足 P2 三投影要求的 384 FLOPs；原 WGRAD 也没有 gate/up/down 独立 FP32 参数梯度生产者。未缩小模型声明、专家权重、训练步数或以状态字段模拟执行。
- 物理执行单层每个非空专家 gate/up/down 各一份 DGRAD `MATMUL`，独立 `SWIGLU_BACKWARD_TIMING`（输入 gate/up 激活 2mI、上游 mI、输出两个 mI，SFU/VEC 为正），再以 FP16 `LOCAL_REDUCE(count=2)` 合并发送回共享层的 dX；gate/up/down 各有 WGRAD `MATMUL` 后通过 `LOCAL_REDUCE V2(count=1)` 真实 FP16→FP32 cast，专家梯度载体 3×H×I×4=384B，参数载体 3×H×I×2=192B。gate rank0 非空 WGRAD 及 FP32 rank-major 树汇合→SGD；rank1 无 token 的 gate **零 GEMM**，保留零工作语义。
- SWIGLU backward 是专用版本化 *timing primitive*，硬件周期与 SRAM 输入/输出读写是真实物理链；该 primitive 不声称数值梯度，`functional=false`。FP16→FP32 cast 为真实半精度解码并将 4B 元素写入目标，旧 V1 LOCAL_REDUCE wire/golden 保持原样。编译校验器对任何缺失 DGRAD 投影、SwiGLU backward、dx 合并、WGRAD cast、FP32 gate reduce/SGD 或 DTE 阶段直接拒绝。
