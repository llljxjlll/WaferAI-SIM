# P3.4-AI — MoE 单 Die Router 动态得分原生矩阵乘

在已签名的 EP1 两层物理前向源上，`MOE_ROUTER` 每层使用真实 FP16 `MATMUL` 生成动态 route score：4×4 activation × 4×1 gate weight → 4×1 score。片段只接受 exact source action、ScheduleSet 的 3 个 BufferABI、FP16 几何及独立 storage；原生记录是 `SRAM_BIND + MATMUL(1,4,4,1)`。官方 SRAM 生命周期装饰后每层 4 条记录，均通过 `CommandFragment.validate_against(GlobalActionDAG)`。官方 `lower_program` 增加 Router 专用分支；其余 COMP 映射未放宽。

测试：`test_moe_full_train_router_score_native`（含已导入的 expert fixture）9/9 PASS；篡改 MATMUL 参数和缩短 gate weight BufferABI 均被拒绝。`py_compile` 与 exact-path `git diff --check` PASS。

整图 `_lower_fragments` 已越过 router，下一阻断为 `moe_dispatch` 缺少物理 opcode。当前 `MOE_COMBINE` 物理 action 只携带 expert output 与 INT32 route table，尚无动态 score BufferABI；仅复制 expert output 不能代表 weighted combine。未发生完整两步 SGD native invocation，训练门禁保持关闭。
