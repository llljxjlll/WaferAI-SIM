# P3.4-U — MoE 单 Die 两层真实前向 IR0 源

状态：仅前向源阶段通过；完整 M1 MoE 两层两步 native SGD 门禁保持关闭。

以真实 `compile_moe_sequence(_manifest(MOE_TRAINING, rows=1, columns=1), source_rank_policy="rank0_shared_spine")` 生成四个 `(step, layer)` unit，再将共同 Dense 训练前向中的两层 MLP 替换为路由、冻结、派发、三投影专家、合并的有类型 MoE 源节点。所得 step0 前向 IR0 有 32 个节点、19 个 trainable StateDecl，其中 11 个 shared、8 个 EP1；两层 residual2 均从各自 MoE combine 读取。每个 EP1 router 只读取一份真实 gate weight；IR0 schema 根据 expert_count 校验路由 operand 数量与形状，显式 EP owner 接受 rank0。EP2 原有两份 gate weight 和 16 个 EP owner 的语义不变。

边界测试分别拒绝 EP1 router 缺失 gate weight、注入伪造第二份 gate weight。`DenseIR0Validator` 仍拒绝将此 MoE typed source 冒充 Dense 训练图；本阶段仅由 `MoeFullTrainForwardValidator` 接受真实前向源。

验证：`python3 -m unittest llm.test.frontend.unit.test_moe_full_train_forward_ir0 llm.test.frontend.unit.test_moe_full_train_ep_ir1_source`。测试输出见 `/tmp/moe_ep1_forward_stage_tests.log`，以最终退出码和摘要为准。
