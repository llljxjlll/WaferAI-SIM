# P3.2-R6：Dense 完整训练全参数/多步血缘验收要求

日期：2026-09-15。范围：M1/P3.2 和 M2/P4.5/P4.6 的**独立源图要求**；没有因列出名字而将物理反向、AdamW 或 M1/M2 标为成功。

## 目标、来源、具体开发

新增 `schema/full_dense_gradient_requirements.py`，仅以生产 `FlexibleDenseTrainPlan.forward_graph` 的源 TRAIN IR0、参数 StateDecl、真实 state accesses、per-shard parameter_templates、TP/DP owner group 为输入。`DenseFullTrainRequirements` 为所有 forward node 保存 source ID，为除 CE 的所有 forward node 保存逆序必须证明的具名 backbone backward ID，CE-forward `loss` producer 与独立输入 `loss_gradient` 保持互斥。它要求至少两个完整 step，但不将旧计划中 `backward_carrier_status=verified`、`full_model_backward_materialized=false` 当作实际物理梯度证据。

关键生产接口 `required_gradient_producers[(step, parameter_state_ref, physical_rank)]` 返回一条 `DenseRequiredGradientPath`：前向消费者、该参数必须真正产生的反向源节点、每一参数的具名 WGRAD、DP group 的规约（DP1 是本地 identity）、SGD、HBM state store、FP32 gradient bytes/FP16 weight bytes、读版本 `step`、写版本 `step+1`、独立 FP32 per-row seed 来源。所有路径都只描述**最低验收要求**；一旦物理链接器接入，必须逐路径核对 SRAM 输出/输入 BufferABI 同值绑定，梯度先于真实 collective/reduction 再先于 optimizer，StateABI 的实际地址与存储量，物理 DAG 的可达依赖，step0 写回支配 step1 读，真实 ProgramIO/finalizer/NpuSim 执行与双独立来源签名。写有 WGRAD 标签、SGD opcode 或一个没有梯度 producer 的 MATMUL motif 不可作为上述证据。

`validate_against(plan)` 完全重算源图 digest、所有 TP/DP owner、前向消费者、backward refs、dtype/bytes、同步 group、每一 step 的读写版本、独立 dLoss seed 和每个参数/rank 键；丢失、重复、旧版本、错 DP group、引用前向 loss 当 seed 都拒绝。production plan 自己的 `validate` 先验执行，防止来源变更后保留旧 requirement ID。

## 测试与真实边界

`python3 -m unittest llm.test.frontend.unit.test_full_dense_gradient_requirements llm.test.frontend.unit.test_full_dense_training_ce_ir0`：7/7 PASS；`python3 -m py_compile` 静态检查。1×1/TP1/DP1、2×2/TP2/DP2、2×3/TP3/DP2 真源两层训练图覆盖全部 source parameter state，每个 step×参数 shard×owner 恰好一条 requirement；2×2 为 30 真实参数 shards × 两 owner × 两 step =120 条路径，源 forward34个 node、33个非 CE backward requirement。2×2 前向额外含 collective，故比 TP1 图的 26 source nodes 更多。故障样本分别删一参数路径、step0 写成旧版本0、误用单成员 DP group、将 dLoss seed 冒用 forward loss、只配置一个 step，均明拒。

此阶段未构建新的参数 DGRAD/WGRAD producer、物理 DP reduction、完整 source IR1/Projection/Schedule/GlobalDAG deep validation，未生成完整多层两步链接/ProgramIO/NpuSim 产物；model/timing/functional/full-model runtime 均未测。当前 CE-only typed source 限 TP1，多 rank CE input sharding 待开发；MoE 必须另列 expert/shared 梯度路径。本阶段仍为源码提交，运行实验产物单独批次提交。
