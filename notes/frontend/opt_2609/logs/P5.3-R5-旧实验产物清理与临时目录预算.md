## 后续自动管理

`scripts/frontend_tmp.py` 提供选择性管理的临时工作区，默认根目录 `/tmp/waferai-frontend-managed`、8 GiB 预算：

```bash
python3 scripts/frontend_tmp.py run --name my-fresh --kind evidence -- python3 path/to/runner.py --output-dir '{tmp}'
python3 scripts/frontend_tmp.py prune
python3 scripts/frontend_tmp.py prune --apply
python3 scripts/frontend_tmp.py release /tmp/waferai-frontend-managed/job-my-fresh-...
```

`run` 将 `TMPDIR` 和 `WAFERAI_TEMP_DIR` 注入子进程，并将命令中 `{tmp}` 替换为专属目录。成功的临时任务自动删除；失败任务默认保留 24 小时用于诊断，成功的证据任务由审阅者显式 `release` 后删除。运行中每 30 秒检测任务目录容量，超过上限时终止该任务进程组；每次启动前还会清理过期任务。`prune` 默认只预览，`--apply` 才执行删除，拒绝接管非空且未标记的根目录，不删除未标记、仍在运行及尚未释放的证据目录。这个机制仅涵盖明确使用 `run` 的新实验；旧目录仍需逐项审计后处理。

验证：`python3 -m unittest llm.test.frontend.unit.test_frontend_tmp` 五项通过，覆盖成功/失败、TTL、预览、活跃进程、未标记目录、证据释放和容量上限。
