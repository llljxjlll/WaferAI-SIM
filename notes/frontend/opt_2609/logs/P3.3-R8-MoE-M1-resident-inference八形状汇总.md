日期：2026-09-16

## 结论边界

MoE resident inference 的 canonical M1 八形状现已全部完成双 Fresh 原生执行和对应冻结版本的 strict resume：

```
1x1, 1x4, 4x1, 2x2, 2x3, 3x2, 3x3, 10x10
```

每个 Fresh 均完整执行 materialize/compile、Prefill + 2 Decode 的三次 finalizer、三次显式 ProgramIO resolver 和一次真实 NpuSim；随后逐字节 reopen 17 个产物，并审计所有 active/compiled Die、PROGRAM_MEMORY、物理 D2D 和 drain。canonical 矩阵共 16 次独立 native runs。另有 `1x3` 两次双 Fresh 作为非 canonical 的矩形扩展证据。

本记录只汇总 MoE resident inference 主矩阵，不更新训练状态，也不据此升级 M1 总体状态。

## Shape-scaled 全 Die profile 语义

本矩阵的测试 `_manifest` 对每个 shape 令 `rank_count = rows*columns`，并同时设置 `num_experts=rank_count`、`EP=rank_count` 和 `active_die_ids=0..rank_count-1`。所以每个 shape 都是对应专家数的 shape-scaled 全 Die profile，而不是把同一个 fixed-expert 模型原样放到不同 mesh。文中“未缩小模型”只表示单个已选择 profile 在实际运行时没有减少它自己的专家、Die 或 sequence。

冻结请求的 Prefill token 数是 `request_count(2) * prefill_tokens(2) = 4`，两个 Decode step 各为 2 tokens；路由构造和校验均使用 `expert = token_index % num_experts`。因此当 `rank_count >= 4` 时，整个 Prefill+2Decode sequence 的 flow endpoint 专家只会是 0..3；Decode 只触达 0..1。其余专家/rank 仍有真实参数、executable stream、active/compiled Die 和 PROGRAM_MEMORY 证据，但应当没有 P2P endpoint drain。

这组 shape-scaled profile 不能替代 fixed-model 跨形状矩阵，也不能替代非默认 rank/core mapping 的补充矩阵；二者需要单独证据。
