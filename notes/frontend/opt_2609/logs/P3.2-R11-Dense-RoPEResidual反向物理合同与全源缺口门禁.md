# P3.2-R11：Dense RoPE/Residual 反向物理合同与全源缺口门禁

日期：2026-09-16。范围是两层 Dense TRAIN 源图的 RoPE Q/K 逆旋转与 residual 双输入梯度的 NEW-only source/physical timing 合同。本阶段没有修改公共 Opcode、PrimId、record codec、ProgramFormat、finalizer 或生产 linker，不生成完整两步训练程序，也不计入 M1。

## 源合同与物理工作

`dense_rope_residual_reverse_requirements.py` 从生产 `FlexibleDenseTrainPlan.forward_graph` 反向扫描真实两层前向图：

- 两个 RoPE leaf 必须来自真实 QKV GEMM 的 packed FP16 GQA 张量，TP rank heads、KV heads、head dim、rotary dim 和 position table 上界一致；每个 rank token 另要求一个尚未物化的 INT32 position trace。
- 四个 residual leaf 必须保存两个不同的真实前向输入 identity；上游 FP16 梯度产生两份独立、同尺寸的 OWNED FP16 输出，不能 alias 输入或彼此 alias。
- TP3 例中 RoPE rank tensor 为 72B，position 为 12B，inverse pairs 与 V pass-through 分别为 12/12；residual 每个输入/输出为 24B。

NEW C++ `BuildRopeQkBackwardTimingWork` 和 `BuildResidualDualDxTimingWork` 对正的 source profile、TP/GQA 关系、position trace、INT32/FP16 dtype、16B SRAM 地址、精确 extent、64KiB 边界及所有 span 不重叠做 fail-closed 校验。它们只返回 bytes/vector/SFU work 和 position digest，没有数值梯度执行、BufferABI 链接或 public record admission。

## 全源缺口门禁

新增 `DenseFullReverseSourceGapGate`，直接复用 `DenseFullTrainRequirements.required_backbone_backward_refs`，把每个 reverse leaf 绑定到一个 typed source family：GEMM dX、Norm dX、collective dX、RoPE Q/K dX、Attention dX、Residual dual dX 或 SwiGLU dX。仅有名字、旧 MATMUL 或 public opcode 不会被推断为 source contract；未知 ref、错误 family、重复或源图漂移均拒绝。

当前切片只承认本批两个 RoPE 与四个 residual source contract：

- TP1 两层图：24 required = 6 contracted + 18 missing。
- TP3/DP2 两层图：32 required = 6 contracted + 26 missing。

`require_complete_source_contracts()` 对上述两种当前图均明确失败。测试中的 complete case 只证明：当调用者显式提供全部 32 个 ref→family source witness 时，source-only gate 可以闭合；它不是物理 primitive、public ISA、数值正确性或 runtime 成功证据。
