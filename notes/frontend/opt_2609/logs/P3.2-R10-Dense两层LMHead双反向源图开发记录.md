# P3.2-R10：两层 Dense LM head 双反向源图

日期：2026-09-15。此次改动仅为训练 IR0 源图的真实梯度连接；M1 Dense 训练尚未完成。

## 目标与实现

在已经完整展开的两层 TRAIN 前向图及独立 dLoss→CE_BACKWARD 源节点之后，从同一 CE dLogits 分别连接：

- 真实 final-norm 保存值 `[M,H]` 与 dLogits `[M,V]` → `backward::T0.lm_head::<真实 StateDecl ID>`，产生 FP32 `[H,V]` 权重梯度；它匹配现有 `DenseFullTrainRequirements` 的 head 参数反向 source ref。
- 同一 dLogits `[M,V]` 与真实 head 权重 StateDecl `[H,V]` → `backward::T0.lm_head`，产生 FP16 `[M,H]` hidden dX；该逻辑节点增加一次真实参数 StateAccess READ。

TP1 为当前准确范围，模型和前向26节点原样保留，loss 本身不充当 dLoss；IR0 结果为29节点、47值及16个 state access，包含两个派生梯度生产者。weight WGRAD、hidden DGRAD 分离；Embedding 的离散 token_ids 不产生输入 dIndex。梯度源节点尚未物化为 GlobalAction、IR1/projection/schedule、record，FP32 参数梯度没有同步、SGD 消费者及下一步回读，故不能计入完整训练或 runtime SUCCESS。
