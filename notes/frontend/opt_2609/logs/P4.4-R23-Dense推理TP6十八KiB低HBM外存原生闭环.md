# P4.4-R23：Dense 推理 TP6 18KiB/Die 低 HBM 外存原生闭环

日期：2026-09-17。承接 [R21](P4.4-R21-TP6十八KiB低HBM整块参数窗口可行性.md) 的源级可行性调查。本记录验收固定 TP6、两层 Dense、Prefill + 2 Decode 的 **M2 推理切片**：同模型同硬件的 `resident_only` 失败与 `offload_blocking` 原生成功配对。三种物理几何为 2×3、3×2、以及 10×10 上固定六个活跃 Die。它不代表任意 TP 或数值推理已完成。

## 实现

- 正式 linked 产物每活跃 Die 含 15 个参数和 4 个 KV StateABI；TP6 共 114 个。每 Die 物理参数 40,416B，最终 KV 容量 3,072B。源级声明和外存物化沿用真实 ABI/LSU 地址，参数对齐空洞的遍历使用真实地址端点拒绝重叠。Resident 峰值需求 19,536B/Die，在 18,432B/Die 下报 `memory_capacity_exceeded`；三种几何使用同一模型摘要 `2e4f864a6abb623f3af3510f2addc5df2d17487b2dd17bf7878268c3a4a34de9`，resident/offload 有用图摘要均为 `bb5541d06bdd8d440b15e9371eac7d691fd1c747f7a11004c057d8d6e9e3e45d`。
- 分页重链接保留生产 `RegionManifest` 与 StateOperandBinding，完整参数 LSU 页共用每 Die `[1600,13888)` 窗口；四个稳定 KV 页位于 `[14016,17088)`，最高地址 17,088B < 18,432B。KV 版本页大小依次为 576、672、768B。每段由正式 finalizer 生成源/分页 NPUP，并由正式 ProgramIO resolver 校验 SRAM 输入/探针。
- 1MiB 有限 external backing 通过一个半双工共享 ingress 连接六个 HBM home：256B/cycle、2-cycle 首延迟、queue depth 与 max outstanding 均为 6。最初沿用 TP4 的 4-slot 设置在六 Die 同时请求第一页时被 NpuSim 明确拒绝；提升到 6 后，同一生产程序完成真实队列传输。非入口 Die 使用已签名、逐跳相邻的 Manhattan 路由；10×10 的物理路由允许经过未运行模型的 Die。
- 原生 pager 从 v1 单 Die、v2 TP4 扩展到 v3 TP6，按物理 Die 而非前四 Die 绑定 HBM backend/Core0 LSU。侧车签名 114 个外存 span、390 个实际 linked LSU DMA gate；仿真时在真实 Load/Store 前后换入/写回，验证 core、地址、大小、段序和 KV 版本，最终检查 pending/dirty/pinned 全零。软件 runner 在整个不可变对象构建阶段使用已有 validation session，减少重复 schema 校验，不改变 NPUP/ProgramIO/侧车字节。

三种几何均完成三段生产 finalizer、ProgramIO resolver、两次独立 NpuSim；KV authority 版本为 0→1→2→3，聚合容量为 0→13,824→16,128→18,432B。六个真实运行核心分别为 `4×active_die_id`。2×3/3×2 六 Die 的 HBM 总量 110,592B，低于参数加最终 KV 的 260,928B；页面转移并非额外虚拟容量。物理 home 每 Die 恰为 18,432B，原生 2KiB stack interleave 可整除该窗口，分页最高地址为 17,088B。

重签负例：2×3 首个 LSU 地址被改动时，原生执行在真实 gate 0 拒绝；把 die1 路由改为非最短路径时在绑定阶段拒绝。10×10 把 die19 路由改为 `[0,19]` 非相邻跳时也在绑定阶段拒绝。既有 TP4 2×2 原生回归通过：12KiB/Die、260 DMA、外存读 334,592B/写 15,360B、两次 Fresh；物理源单测 3 项通过。

这些结果是 timing 模式，报告中 `functional=false`；它们证明真实 payload DMA、ProgramIO 边界、状态版本与时序排空，不宣称数值推理正确性。此实现覆盖固定 TP6 模型与上述几何；更广的任意 TP/mesh 以及训练路径由其他阶段单独验收。
