# P3.2-R4：Norm 与 Attention 物理反向 timing 原语

## 目标与范围

在 Dense 训练的真实反向记录进一步连通之前，为归一化的 activation-gradient 和因果注意力的 packed-QKV-gradient 预留具名内部 NPU timing primitive。两种 primitive 只统计公开的工作量，不计算数值梯度；独立程序仍需显式管理 forward tape、upstream gradient 和输出 gradient 的 SRAM 分配与传输。

本阶段没有把这两种 primitive 注册为外部可执行 Opcode。TP16 全负载运行正在使用冻结的 `record_codec.cpp`、外部 record schema 与工具 SHA；在冻结解除之前只推进独立 Prim wire 和工厂验证。这些内部原语不计为完整两层 Dense 训练运行，也不补齐 CE、embedding、MLP、参数梯度和状态连通。

## 开发内容

- 新增内部 `PrimId` 70/71 和连续、内部可用的 Prim manifest 项。PrimFactory 的静态注册名称分别是 `norm_backward_timing` 与 `attention_backward_timing`。
- 两者的通用严格 Prim wire 包含真实的 forward-input、upstream、output 三处 SRAM byte offset 和 rank/profile 参数。序列化及反序列化都拒绝 legacy wire、非 FP16、缺失参数、非正形状、非 16 B 对齐、u16 SRAM 尾地址越界及三个 tensor 范围重叠。
- Norm 支持 RMS(0) 与 Layer(1) 的 activation-gradient timing profile；明确 rank rows、hidden 和 TP，按模式给出 SFU/vector ops。它尚不产生 gamma/beta 或 RMS 缩放权重的参数梯度。
- Attention 支持 uniform sequence 的因果训练 profile；确认 rank Q heads、rank KV heads、head_dim、TP、sequence 数、token 数与精确 `pairs = sequences × (tokens/sequences) × (tokens/sequences+1)/2`。packed-QKV tensor、forward-output upstream tensor 和 packed-QKV-gradient tensor 的字节数分别由 rank shape 严格导出，按精确 pair 数导出 EXU/SFU/vector ops。非 uniform 或额外 mask/profile 暂不在这版承诺内。
- `NpuSim --isa-v1-selftest` 增加独立正负 Prim wire 与 work 自测；现有 manifest/factory inventory 更新为内部 71 项。
- 把 ISA 与 CollectiveLaunch 自测里硬编码的“ID 70 是第一个未分配 PrimId”改为由 `kMaxAssignedPrimId + 1` 导出，保证新内部 ID 不会让旧负例误报。
- 修复 NPU cost 自测的未初始化 `TaskCoreContext.cid`：直接 production timing probe 在 WorkerCore 赋值前会读取 core id；优化构建曾读到 `-48` 并在此路径段错误。自测构造后明确设 `cid=0`，不改变生产计算。

## 验证

- CMake 在专用 `build-dense-reverse-native` 目录配置 EXIT 0。
- 使用实际 CMake include 路径，对 primitive 源码、专有 wire 自测和 ISA 自测三个 C++ 翻译单元的 `-fsyntax-only` 均 EXIT 0。
- 专用优化版 NpuSim 完整构建与链接 EXIT 0；执行 `build-dense-reverse-native/npusim --isa-v1-selftest` EXIT 0。最终输出：manifest/factory 1203 checks PASS、record codec 1266 PASS、Prim wire 608 PASS、专有 backward timing Prim wire/work 17 PASS、program format 669 PASS、record lowering 398 PASS、CollectiveLaunch 40 PASS；没有 `FAIL` 标记。
- 17 项专有检查包括两种工厂 ID、三地址/FP16 rank work、真实 taskCore 计费、wire round-trip、保留位篡改、norm 模式/attention causal pair 在 wire 上被篡改、SRAM overlap、未知模式及无效 GQA/profile 的拒绝。输出保存在本地 `/tmp/p3-r4-isa-v1-selftest.stdout`，未把构建产物或自测输出混入源码提交。
